# Review fix pass — implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix every defect the 2026-09-15 solution review (R0–R9) found, so that the claims, the gates and the reproduction path say exactly what the evidence supports.

**Architecture:** Fixes land in dependency order. Tooling robustness comes first, then the A/B extraction bug, then the answer-free derivation, which reorders the C/D/E stages. The claims (E2, net 806, AC6) follow, then the verification machinery, then the documents, and finally a fresh-environment reproduction. Every derived artifact is regenerated by its stage and never hand-edited. Every gate change lands in the same task as the claim it guards.

**Tech Stack:** Python 3.11.15 (`.venv`), gdstk 1.0.1, klayout 0.30.12, matplotlib 3.11.2, Icarus Verilog 12, git. The project's test harness is its gates (`tools/checks/check_*.py`, run by `tools/checks/run_all.py`), not pytest.

**Spec:** the review findings R0–R9, as summarised in the consolidated verdict of 2026-09-15. The user decisions recorded below are part of the spec.

def uniqueness(class_of: list[int] | None, node_budget: int = 4_000_000) -> dict:
    """Is the solution unique? Only a *finished* search may say yes.

    `count_solutions` stops at its node budget and returns what it has; a budget-stopped search that
    had found one solution used to be counted as unique (review R5). `complete` is true iff the search
    either finished inside the budget or found a second solution.
    """
    boards: list[tuple] = []
    total, nodes = count_solutions(class_of, cap=2, node_budget=node_budget, collect=boards)
    complete = nodes <= node_budget or total >= 2
    board = None
    if complete and total == 1:
        board = sorted((r, c) for r, pair in enumerate(boards[0]) for c in pair)
    return {'solutions': total, 'nodes': nodes, 'complete': complete,
            'unique': complete and total == 1, 'board': board}

from tools.checks import _regen as R          # noqa: E402

checks: list[dict] = []

```python
def region_free_count(n: int = 11, per: int = 2) -> int:
    """Boards with `per` stars in every row and column and no two adjacent, counted exactly.

    Dynamic programming over rows; the state is (previous row's mask, column loads). A column that
    still needs k stars with `left` rows to go can take at most ceil(left/2) of them (no vertical
    adjacency), and one just used loses the next row, which prunes states that cannot finish. With
    per=1 this is Hertzsprung's problem (OEIS A002464), which the gate uses as the cross-check.
    """
    masks = [m for m in range(1 << n) if bin(m).count('1') == per and not m & (m << 1)]
    full = (1 << n) - 1
    states = {(0, (0,) * n): 1}
    for r in range(n):
        left = n - r - 1
        nxt: dict = {}
        for (prev, loads), ways in states.items():
            forbid = (prev | prev << 1 | prev >> 1) & full
            for m in masks:
                if m & forbid:
                    continue
                new = tuple(v + (m >> c & 1) for c, v in enumerate(loads))
                if max(new) > per:
                    continue
                if any(per - new[c] > (left + (0 if m >> c & 1 else 1)) // 2 for c in range(n)):
                    continue
                nxt[(m, new)] = nxt.get((m, new), 0) + ways
        states = nxt
    return sum(w for (_m, loads), w in states.items() if all(v == per for v in loads))
```

def letter_classes(classes: dict[str, list[int]]) -> dict[str, str]:
    """Which classes are drawn as a letter: the class's cells, cropped to their bounding box, equal a glyph."""
    found = {}
    for flop, cells in classes.items():
        rc = [(i // 11, i % 11) for i in cells]
        r0, c0 = min(r for r, _ in rc), min(c for _, c in rc)
        h, w = max(r for r, _ in rc) - r0 + 1, max(c for _, c in rc) - c0 + 1
        pic = tuple(''.join('#' if (r0 + y, c0 + x) in set(rc) else '.' for x in range(w))
                    for y in range(h))
        for letter, glyph in GLYPHS.items():
            if pic == glyph:
                found.setdefault(letter, flop)
    return found
