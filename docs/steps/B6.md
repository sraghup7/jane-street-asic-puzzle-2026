## 1. What was emitted


Net naming is deliberately mechanical, so the file can be read back and checked against the
artifacts it came from — the gate does exactly that:

| kind of net | name | why |
|---|---|---|
| carries only supply pins | `VPWR` / `VGND` | those are the chip's own port labels for them |
| a documented port sits on it | the port label (`clk`, `rst_n`, `enable`, `I`, `O[0..7]`, `success`) | 13 ports, from B5's table |
| everything else | `n<cluster>` | `cluster` is B3's own net identity |

No net is renamed, merged or dropped, so the inverse of that map is exact. Pins B4 could not assign
are emitted as **explicit empty connections** (`.VPB()`) rather than quietly omitted, so the file
shows the same 972 pins the artifact records, from the same two causes (A5's gap classes). A pin
with no net in the layout gets no net in the Verilog.

## 2. Where the cell semantics come from

Δ2 was chosen up front: the models are grounded in the **labels the chip carries**, not in a PDK.
Three rules do all the work, and every one of them is a read of the artifact:

1. **A pin label ending in `_N` is the complemented form.** One rule therefore covers both
   `and4bb` (`A_N,B_N,C,D` — inverted on the left) and `or4bb` (`A,B,C_N,D_N` — inverted on the
   right), instead of two family-specific exceptions. This is the single most useful thing the
   labels give us for free.
2. **The `a<digits>o` / `o<digits>a` family names parse into their own group structure.** A digit
   gives one group's arity, a following run of `b`s says how many of *that* group's inputs are
   complemented, and a trailing `i` inverts the output. So `o2bb2a` is `2bb` then `2`:
   `X = ((~A1_N | ~A2_N) & (B1 | B2))`, and `a221o` is `X = (A1 & A2) | (B1 & B2) | C1`.
3. **Polarity of the sequential controls comes from the top-level port that reaches them.**
   `RESET_B` and `SET_B` assert when driven *low*, and the artifact says so directly: the port
   labelled `rst_n` resolves to the very net carrying the design's 84 `RESET_B` terminals.

Every master's parse is **asserted** against A3's actual pin set, so a convention mismatch fails
loudly instead of producing a plausible wrong model. The `hi`/`lo` outputs of the tie cell and the
`DIODE` input of the antenna diode are read the same way — from the labels.

These models are hypotheses. Phase C tests them against two independent oracles: **C2** (the
warm-up's known RTL) and **C1** (the recorded waveform). They are not trusted because they look
right.

## 3. What B6 caught: a wrong direction in B5's committed artifact

B6's models are generated from family names, so `cells.py` refused to build a model whose family
says `Y` while B5's direction table says `A1`:

```
AssertionError: sky130_fd_sc_hd__a31oi_2: family name says output Y, B5 derived ['A1']
```

That assertion is why this step stopped rather than emitting a netlist. It led to the defect
recorded in `docs/verification.md` §9: B5's structural solver had **manufactured** a driver on
net 806 (a net with two input pins and nothing else), and its own check had certified the
fabrication. Direction now comes from the pin labels with the structural solver demoted to auditor;
the analysis and the fix are in `docs/steps/B5.md` and commit `b9367ec`.

**The pattern worth keeping:** a cross-step *interface* assertion caught what the upstream step's
own gate had certified. B6 now runs the same cross-check in the other direction — the output pin
each model drives must equal the one B5's table names — so a regression in either direction fails.

## 4. What the gate caught: three broken flip-flop models

`cells.py` left `predicted_out = None` for the sequential families, so the renderer declared
`input Q;` on `dfxtp_2`/`dfrtp_2`/`dfstp_2` and emitted a stray `reg None;` — which **`iverilog`
accepted**, `-Wall` included, exiting 0 with empty stderr. The models would have simulated wrongly.

The gate found it by re-deriving each port's direction from A3 + B5 rather than trusting the
generated text. Two lessons, both worth more than the fix:

* **a clean compile is necessary but nowhere near sufficient.** `iverilog -t null` is the plan's
  stated verification for B6, and it passed on a netlist whose flops had no output.
* the fix is in the interface assertion, not the compiler invocation: the gate now checks that each
  model's port list, each port's direction, and the driven output pin all agree with the artifacts.

The change-detection control is kept too: the gate also compiles a deliberately broken file with
the *same* invocation and requires it to be rejected, so a compiler that silently accepts anything
cannot be mistaken for evidence.

## 6. The one undriven wire, honestly

`build/puzzle.v` contains `wire n806;`, connected to the `A1` inputs of `i0523` (`a31oi_2`) and
`i0525` (`a311o_2`), and driven by nothing. That is B5's finding carried through without
embellishment — net 806 is the design's only net with no driver, it is entirely on li1, and it is
*not* a split net or a missing via rule (both candidates sit on the same layer with the same engine
configuration; same-layer shapes that touch would already have merged).

The plan's original verification clause said "no undriven wires". That claim is false here, and
asserting it is precisely how B5 invented a driver to satisfy it. **Amended clause:** *exactly one
wire is undriven, it is named, and it is the one the artifact enumerates.* B7 and C1/C2 decide
whether it is a dangling structure or a decoy in this GDS.

   the warm-up, but B2's comparison predates the flatten fix; the warm-up has since been re-run
   through the flattened engine with an exact match (84 nets and 285 terminals both sides, 0

2. **The models are untested behaviour.** Nothing here proves `a2111oi_2` really computes
   `~((A1&A2)|B1|C1|D1)`; it proves the model matches the name and the pin set. C2 is the test that
   makes them trustworthy, and C1 is the test that makes the *netlist* trustworthy.
3. **`net 806` is the one thing that is not a netlist.** Everything downstream must tolerate a
   driverless wire, and C1 will show it as X — which is the correct reading of a real dangling
   structure.
